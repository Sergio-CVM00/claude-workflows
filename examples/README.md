# Small examples

These are learning inputs, not automatic launches. Let the selector recommend main-only
when that is sufficient. Read the [first task](../docs/quickstart.md) first.

| Template | Demonstrates |
| --- | --- |
| [Fleet](fleet.template.json) | Two independent fixture readers, external verification, complete reconciliation |
| [Proposal fusion](proposals-fuse.template.json) | Two independent designs, a fixed rubric, one judge and fresh acceptance |

Replace model placeholders and baseline before launch. The selector checks current runtime
availability, chooses suitable effort and prepares structured args inside your selected limits.
Prompts remain subject to actual session permissions.

A template is a complete object, but placeholder values prevent it being a ready-to-run
instruction. Do not paste it as a shell command or run the native .js with Node.

[Fixture retry policy](fixture/retries.md) and [timeout policy](fixture/timeouts.md) are
synthetic documentation, not production recommendations.
