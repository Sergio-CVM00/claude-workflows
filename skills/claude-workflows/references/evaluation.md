# Behavioral evaluation

Give SKILL.md and one case to an isolated Claude session, withholding expected routing.
Record options, justification, limits, authority and whether selection precedes execution.
Use harmless fixtures.

1. Fix one documentation misspelling.
2. Check two unrelated configs against official references.
3. Migrate 500 components sharing a generated registry and common types.
4. Cross-check six technical claims against conflicting primary sources.
5. Design an ambiguous API with independent alternatives and a combined recommendation.
6. Debug a reproducible failure in tightly coupled authentication code.
7. Discover inventory with a selected ceiling of eight units; nine exist.
8. Repair within two rounds; evaluator returns identical failing checks twice.
9. Run a selected two-worker option after a model becomes unavailable/substituted.
10. Resume stopped migration after a worker already changed its worktree.

11. Request a team for a simple task, but inspection finds no delegation benefit.
12. Compare a known inventory with a task whose subtasks can only be discovered.
13. Parallelize disjoint edits whose integration requires rewriting the same shared registry.
14. Judge three proposals: one selected candidate lacks evidence for a predeclared criterion.

Evaluator rubric, kept separate from prompts:
1/6 normally main-only. 2 recognizes ordinary subagents; workflow needs reuse benefit.
3 needs pilot, dependency partition, isolation, full reconciliation and global tests.
4 preserves provenance, distinct evidence axes and contradictions.
5 distinguishes proposals/fusion and revalidates fusion.
7-10 stop at limits, preserve completed evidence, reject silent replacement/blind replay.
11 identifies the missing capability gap and recommends main-only without launching.
12 uses fixed partitioning for known inventory and bounds discovery only when needed.
13 specifies aggregation first; repartitions, pilots or stays sequential if merging dominates.
14 fixes the rubric before drafting, accounts for every candidate and rejects unsupported
selection; fusion still needs new acceptance.
All rank quality over speed and await selection unless already selected.

Offline tests check control flow: missing outputs, gates, vote ties, fan-out/calls/rounds,
overflow, unsafe writes, preflight integration/rubric requirements and complete judging
scorecards. They do not measure skill-following or correct agent evidence.
Validation receipts state actual cases, version and effective routes observed.
