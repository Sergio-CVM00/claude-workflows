# Activity recipes

| Activity | Default progression | Acceptance boundary |
| --- | --- | --- |
| Small implementation | Main session; reviewer only if risk warrants it | Actual diff/tests |
| Audit | Inventory -> fleet readers -> targeted verification -> reconciliation | Every path covered; reproduce findings; missing readers visible |
| Migration | Dependency map -> pilot -> isolated fleet -> integration -> global checks | Per-file green is insufficient; shared dependencies need coordination |
| Deep research | Source map -> independent evidence axes -> claim checks -> synthesis | Direct URLs/dates/provenance; count underlying evidence, not duplicated links |
| Difficult planning | Independent proposals -> select/fuse -> feasibility challenge | Constraints, contradictions and new validation of fusion |
| Debugging | Main hypothesis/test loop; a few investigators if genuinely separate | Reproduction and discriminating experiments |
| Unknown inventory | Bounded discovery -> workers -> reconciliation | Overflow returns to session; never truncate |
| Repeated repair | Main or scripted worker/evaluator loop | External failing checks, progress/round limits and actual rerun evidence |

Size by independence/information gain. Small source cross-checks often need ordinary
subagents rather than a script. Research separates retrieval from interpretation and primary
evidence from vendor/author claims.
